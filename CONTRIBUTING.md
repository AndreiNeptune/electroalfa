# Contributing to Electroalfa

We welcome contributions! To maintain code quality and consistency, please follow these guidelines:

## Development Workflow

1.  **Branching**: Use descriptive branch names (e.g., `feat/add-product-filter`, `fix/broken-link`).
2.  **Commits**: Follow [Conventional Commits](https://www.conventionalcommits.org/) (e.g., `feat: ...`, `fix: ...`, `chore: ...`).
3.  **Code Style**: Ensure your code passes linting (`npm run lint`) and type checks.
4.  **Security**: Never commit secrets or `.env` files. Ensure `.gitignore` is up to date.

## Pull Request Process

1.  Create a new branch from `main`.
2.  Implement your changes and add tests if applicable.
3.  Ensure the project builds locally (`npm run build`).
4.  Open a PR with a clear description of the changes.

Thank you for helping us build a better platform!
